Docker commands - Windows mode
===============================

1.Build the image:
docker build -t collection_program_restapi .

2.Run the container (maps container port 8000 to host port 8000):
docker run -p 5080:8000 --name run_collection_program collection_program_restapi

3.Run in detached mode (background) with a name:
docker run -d -p 5080:8000 --name run_collection_program collection_program_restapi

4.Run with live code reload, mounting the project folder (PowerShell syntax):
docker run -p 5080:8000 -v ${PWD}:/app --name run_collection_program collection_program_restapi

5.List running containers:
docker ps

6.View logs of the running container:
docker logs -f run_collection_program
-------------------------------------------------------------------------------------------------

Stop the container:
1.docker stop run_collection_program

2.Remove the container:
docker rm run_collection_program

Remove the image:
docker rmi collection_program_restapi

Open a shell inside the running container:
docker exec -it run_collection_program bash

Rebuild and restart from scratch (stop, remove, rebuild, run):
docker stop run_collection_program
docker rm run_collection_program
docker build -t collection_program_restapi .
docker run -d -p 5080:8000 --name run_collection_program collection_program_restapi
