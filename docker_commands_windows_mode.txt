1. Build Docker image

docker build -t collection_program_restapi .


2. Run container

docker run -d -e PYTHONUNBUFFERED=1 --env-file env_vars.env --name collection_program -p 5080:80 collection_program_restapi


3. Show logs

docker logs --tail 100 -f collection_program


You can also run 1. 2. 3. in one:

WITHOUT auto-reload:
docker build -t collection_program_restapi .; docker run -d -e PYTHONUNBUFFERED=1 --env-file env_vars.env --name collection_program -p 5080:80 collection_program_restapi; docker logs --tail 100 -f collection_program

WITH auto-reload:
docker build -t collection_program_restapi .; docker run -d -e PYTHONUNBUFFERED=1 -e WATCHFILES_FORCE_POLLING=true -v C:\Users\gjyli\PycharmProjects\collection_program_restapi:/app --env-file env_vars.env --name collection_program -p 5080:80 collection_program_restapi uvicorn main:app --host 0.0.0.0 --port 80 --reload; docker logs --tail 100 -f collection_program

TO STOP IT:

1. docker stop collection_program

2. docker rm collection_program

You can also do both of them in one:
docker stop collection_program;  docker rm collection_program
